# Ask Appliance Repairs Ltd Website

A professional, responsive website for Ask Appliance Repairs Ltd, providing appliance repair services across London.

## Features

- **Responsive Design**: Mobile-first approach with full responsiveness across all devices
- **SEO Optimized**: Comprehensive SEO implementation with meta tags, structured data, and performance optimization
- **MVC Architecture**: Clean separation of concerns following Model-View-Controller pattern
- **SOLID Principles**: Well-structured code following SOLID design principles
- **Cookie Consent**: GDPR-compliant cookie consent banner
- **WhatsApp Integration**: Floating quote button with WhatsApp integration
- **Accessibility**: WCAG compliant with proper focus states and semantic HTML
- **Performance**: Optimized for fast loading and smooth user experience

## Customization

### Colors
Update colors in `AppConstants.js`:
```javascript
PRIMARY_COLOR: "#000066",
SECONDARY_COLOR: "#ffffff",
ACCENT_COLOR: "#ff6600"
```

### Content
Update text content in `AppConstants.js`:
```javascript
COMPANY_NAME: "Ask Appliance Repairs Ltd",
WHATSAPP_NUMBER: "+44 7340 002079"
```

### Images
Replace placeholder images in the `/images/` directory:
- `logo.png` - Company logo
- `hero-bg.jpg` - Hero section background
- `favicon.ico` - Website favicon
- Service icons in `/images/service-icons/`
